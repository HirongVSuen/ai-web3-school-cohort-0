## 学习路径

### 🟢 最小路径（必读/必做，约 30 分钟）

阅读 Handbook 核心知识节点，理解 Agent 为什么需要链上上下文：

1. **为什么要学这个** — Agent 知道链上状态才能避免错误建议和危险交易
2. **第一性原理** — 知道概念没用，需要具体网络、合约、池子、价格、余额、allowance
3. **知识节点必读**：
   - **On-chain Data** — 链上数据的字段规范（chain id, block number, contract address, method, 返回值, 读取时间）
   - **Contract Docs** — ABI 只能给函数签名，NatSpec/README 补足语义
   - **ABI / Event** — 能调用 ≠ 应该调用，写交易前需权限/余额/slippage 检查
4. **最小实践** — 找一笔公开交易，收集 chain id/block/from/to/method/value/logs，标出链上事实和自己的解释

### 🟡 推荐路径（约 1-1.5 小时）

在最小路径基础上，继续阅读并动手：

1. 继续阅读 **Transaction History** — 理解交易历史如何为 Agent 提供决策依据
2. 阅读 **Explorer Context** — 区块浏览器的数据结构如何被 Agent 消费
3. 阅读 **Indexing Context** — The Graph 等索引器如何把事件整理成可查询上下文
4. 动手实践：用 curl 或 viem 读取一个地址的 ETH 余额和交易历史
5. 写一个简单脚本，把 chain id + block number + 余额数据格式化成 Agent 可读的 context block

### 🔴 挑战路径（约 2+ 小时）

在推荐路径基础上：

1. 阅读 **Citation** — 给 Agent 上下文中每个关键结论附上交易哈希或 explorer 链接
2. 实现一个函数：自动从链上获取合约 owner 并验证合约版本是否匹配文档描述
3. 在一个真实的 Agent 调试场景中，验证链上数据 context block 的有效性
4. 可选：使用 Etherscan API / The Graph 查询真实数据并格式化输出

### 扩展阅读

- Ethereum JSON-RPC API：理解链上数据如何通过 RPC 被读取
- Ethereum Events and Logs：理解事件和日志如何成为链上上下文来源
- Etherscan API Docs：了解区块浏览器数据接口如何辅助查询
- The Graph Subgraphs：学习如何把事件整理成可查询上下文
