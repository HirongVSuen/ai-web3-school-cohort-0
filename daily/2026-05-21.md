## 学习记录

### 核心概念

#### Chain-aware Context 回顾
- **On-chain Data**: Agent 读取链上数据需附带证明元数据（chain id, block, contract, method, time）
- **Contract Docs**: ABI 不够，需 NatSpec/README 补语义，但文档可能过期
- **ABI/Event**: 能调用 ≠ 应该调用，写交易前需 simulation
- **Explorer Context**: 给 explorer link 比只写"交易成功"更可靠

#### Web3 Tool Use 新内容
- **RPC Tool**: 只读可放开，写入必须隔离
- **Contract Read**: 低风险但需防误读网络/合约/ABI
- **Contract Write**: 需白名单合约 + 额度策略 + simulation + 用户确认
- **Wallet Tool**: 连接/签名/发交易/授权/撤销 → 分拆成独立动作
- **Tool Permission**: 最小权限原则，不要给万能工具
